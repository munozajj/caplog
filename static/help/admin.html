Admin

This page is only for admin accounts. Open it at /admin. Sign in at /admin/login. An admin cannot edit, hide, or delete an entry. Every settings change and every account change is a permanent system entry. Passwords, session tokens, and certificate private keys are never written into that entry.

The logbook page does not link here. Signing in on the logbook does not open these pages, and signing in here does not sign you in on the logbook. The admin session cookie is caplog_admin. Its path is /admin. A request without that session returns HTTP 401. Only an account with the admin role, including the master admin, can sign in here. Failed admin sign-ins count toward the same lockout as logbook sign-ins.

Before the logbook is configured, /admin shows the setup form. That form sets the title and the master admin account, and it can be completed only once. Until then, the logbook address shows only the message "This logbook has not been configured by the administrator yet." and user requests are refused.

Settings

  • post_mode: both, guests, or accounts.
  • users_may_change_display: whether people can change what the logbook shows, including post_box (top, bottom, left, right, or center).
  • site_fqdn: the host name used in links, exports, and the PDF header.
  • https_enabled, https_port, http_redirect: HTTPS on a separate port. Restart CapLog after a certificate change. Leave these off when a reverse proxy or a Kubernetes Ingress terminates TLS, and set trusted proxies so the stored address is the person, not the proxy.
  • cert_warn_days: warn when the certificate expiry is inside this many days.
  • ntp_enabled, ntp_server, ntp_threshold: compare the clock. The default threshold is 2 seconds. CapLog does not set the clock. Run chrony or NTP on the host or on the Kubernetes nodes. The Helm value timeCheck.enabled must also be true or the network policy blocks UDP port 123.
  • max_entry_length: default 500.
  • accent_color: a color such as #0d6e6a.
  • show_ips: whether IP addresses can be shown. They are still stored.
  • guest_name_rules: letters, spaces, apostrophes, and hyphens.
  • feature_search, feature_tags, feature_notice, feature_corrections, feature_rate_limit, feature_scheduled_export, feature_display_page: each extra feature.
  • notice: the pinned notice. Clearing it is also logged.
  • tags: comma-separated names the poster can choose.
  • rate_limit_count and rate_limit_window: posts per IP address and per account.
  • login_max_failures and login_lock_minutes: sign-in lockout.
  • export_every, export_pdf, export_keep: scheduled JSON backups, optional PDF, and how many files to keep on the backup volume.
  • show_number, show_name, show_time, show_ip, show_poster, show_tags, time_zone, clock, post_box: display defaults.

Accounts

Accounts are local. There is no external identity provider. Passwords are hashed with argon2id. The first admin cannot be disabled or changed to a normal user. Disabling another account does not hide that person's entries.

Certificates

Generate a self-signed certificate or upload a PEM certificate and an unencrypted PEM private key. The key is stored on the certificate volume as mode 0600. It is not in the database, the logs, or the repository. Restart the container or the pod before the process listens with the new files.

DNS, time, and deployment

CapLog does not run a DNS server. Set container DNS with Compose dns: on the app service, or use the cluster DNS. Create an A record or a CNAME record for site_fqdn at your DNS host.

Time sync stays on the host or the nodes. A warning banner is shown to everyone when the drift is over the threshold.

Docker Compose publishes the app on the non-internal web network. PostgreSQL stays on the internal caplog network. Certificate files use the caplog-certs volume. Backups use caplog-backups. Helm has the same volumes, an HTTPS service port when https.enabled is true, and UDP 123 only when timeCheck.enabled is true.
